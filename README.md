This project introduces an AI-driven system designed to identify medicinal plants from leaf images and provide their therapeutic uses. Leveraging the Xception model within a Convolutional Neural Network (CNN), the system is trained on the Indian Medicinal Leaves dataset from Kaggle to achieve high classification accuracy. The solution includes a web interface where users can upload plant images and instantly receive predictions along with AI-generated medicinal information via the Google Gemini API. Performance is evaluated using accuracy, precision, recall, and F1-score. By merging deep learning and natural language AI, the project supports public health awareness, educational outreach, and digital preservation of traditional plant knowledge.
